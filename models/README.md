# Models Directory

Trained model artefacts, written by `scripts/train_models.py` and
`scripts/train_eval_datasets.py`. Model binaries are git-ignored and are
regenerated by re-running training.

```
models/<dataset>/
├── logreg.joblib
├── random_forest.joblib
├── svm_rbf.joblib
├── lstm.pt + lstm_arch.json      (NSL-KDD only)
├── *_selection.json              full validation grid search per model
└── training_summary.json         per-dataset training record
```

The `*_selection.json` records contain every hyperparameter combination with
its validation score and fitting time, and **no held-out figure** — which is
what makes the claim that model selection used validation data alone auditable
rather than merely asserted.
